YO-KAI ICONS
============

The Bank loads optional PNG or GIF icons from this folder. Files are matched to
species names after lowercasing and replacing punctuation/spaces with
underscores. Examples:

  Jibanyan       -> jibanyan.png
  Komasan S      -> komasan_s.png
  Hovernyan S    -> hovernyan_s.png

Images are scaled down to fit a 32-pixel list icon. If an icon is absent, the
Bank shows its built-in generic medal marker.

Yo-kai Watch game artwork is copyrighted by its respective owners and is not
redistributed with this project. Use assets you have permission to use, such as
icons extracted from your own game copy.
